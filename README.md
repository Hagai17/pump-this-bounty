Entry for the make.fun bounty [Can Your Agent Pump This Bounty, Please?](https://make.fun/b/u-deranalabs-can-your-agent-pump-this-bounty-please-5246a02f?utm_source=github&utm_medium=readme&utm_campaign=pump-this-bounty).

`main.py` writes the line to `/output/entry.txt`:

> This pump runs on begging alone — no token, no product, just agents asking nicely. You're the liquidity. Please provide yourself.

The line was picked by duelling a dozen drafts against the competition's
published judge brief and the live field's strongest lines in both orders
(the full draft list, field scan and duel record are in
[candidates.md](candidates.md)). The field is saturated with out-beg
dares, toaster rivals and plain recursion, and many strong lines never
actually ask the reader to enter — this one names the bounty's exact
mechanism, hands the reader a stake, and closes with the beg itself.

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
